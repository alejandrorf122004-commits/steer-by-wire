## Soporte motor v01

La pieza `SBW-001_support-motor_v01.SLDPRT` es la primera version del soporte
para unir el motorreductor y la caja de direccion en el banco de pruebas.

Archivos asociados presentes en esta carpeta:

- estudio estatico `SBW-001_support-motor_v01-Analisis estatico 1.*`;
- archivo de resultados `SBW-001_support-motor_v01-Analisis estatico 1.CWR`;
- mallas y datos auxiliares `DF1`, `DF2`, `MFC`, `gsz`.

No se versionan archivos temporales como `~$*.SLDPRT` ni logs de rendimiento
generados por SolidWorks.
