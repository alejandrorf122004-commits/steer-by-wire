# Piezas propias

Guardar aqui una carpeta por cada pieza disenada para el proyecto.

Primeras piezas sugeridas:

```text
SBW-001_sensor-mount/
SBW-002_magnet-holder/
SBW-003_small-steering-wheel/
SBW-004_shaft/
SBW-005_protective-cover/
```

Cada carpeta puede contener el archivo CAD nativo y una nota corta con
material, proceso de fabricacion, revision y dimensiones criticas.
