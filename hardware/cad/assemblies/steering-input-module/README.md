# Steering input module

Ensamble del pequeno volante utilizado para desarrollar y validar la lectura
del AS5600 antes de instalarlo en el vehiculo.

## Contenido previsto

- volante;
- eje y soporte;
- portaiman;
- iman diametral;
- AS5600 de `vendor/as5600/`;
- soporte del sensor;
- tornilleria, separadores y tapa.

## Requisitos iniciales

- El iman debe quedar centrado sobre el chip AS5600.
- La separacion entre iman y sensor debe poder ajustarse.
- El iman no debe tocar la placa durante el giro.
- El sensor debe poder desmontarse sin destruir el soporte.
- Debe existir retencion mecanica para el iman.
- El cableado no debe soportar esfuerzos ni rozar partes moviles.

El primer ensamble puede llamarse:

```text
SBW-A01_steering-input-module_v01
```
