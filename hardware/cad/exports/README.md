# Exportaciones CAD

Archivos derivados para fabricar, compartir o visualizar:

- `step/`: intercambio de solidos y ensambles;
- `stl/`: impresion 3D;
- `dxf/`: corte o perfiles 2D;
- `images/`: capturas y renders para documentacion.

Los archivos nativos editables permanecen en `parts/` y `assemblies/`.
