# Archivos STL

Guardar aqui los STL exportados para impresion 3D.

Usar el mismo nombre y revision de la pieza original:

```text
SBW-001_as5600-sensor-mount_v01.stl
SBW-002_bearing-mount_v01.stl
SBW-003_magnet-holder_v01.stl
```

Los STL son archivos derivados. Las piezas editables de SolidWorks permanecen
en `hardware/cad/parts/`.

La skill `export-cad-to-stl` puede regenerar automaticamente esta carpeta
despues de guardar cambios en las piezas.
